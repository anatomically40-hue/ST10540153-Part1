1. Project Overview

The Soshanguve Community Forum is a non-profit community project that aims to provide useful information to residents of Soshanguve.

The website provides information about community safety, services, volunteering and communication with the forum. It aims to make important community information easier to access online.

The project focuses on residents watching out for one another and encouraging community participation.

2. Website Goals

The main goals of the website are to:

Provide information about the Soshanguve Community Forum.
Share community safety information.
Provide information about available services.
Allow residents to make enquiries.
Encourage volunteering and community participation.
Help residents access important contact and emergency information.
3. Website Pages

The website contains five main pages.

Home (index.html)
Introduces the Soshanguve Community Forum and its purpose.

About (About.html)
Provides information about the forum and its activities.

Services (Services.html)
Explains the services and support offered by the forum.

Enquiry (Enquiry.html)
Provides a form for residents to send questions and enquiries.

Contact Us (Contact Us.html)
Provides contact information and emergency contact details.

4. Technologies Used

The following technologies were used:

HTML5 – to create the website structure and content.
CSS3 – to style the website and create responsive layouts.
JavaScript – to support interactive website features and form handling.
Leaflet – to support the interactive map.
GitHub – for version control and storing project files.
Netlify – for hosting and publishing the website.
5. Website Features

The website includes:

Navigation between the five website pages.
Responsive layouts for different screen sizes.
Community information and safety content.
An interactive map using Leaflet.
A community photo gallery.
Interactive website elements.
Enquiry and contact forms.
Form validation and user feedback.
Images and icons to support the website content.
Search engine files, including robots.txt and sitemap.xml.

Form status: The forms are included in the website, but live form submission is still being tested and requires further configuration.
